Status Sambungan Semasa:

Kenapa "Tidak Dapat Menghubungkan Awan" di Vercel / WhatsApp?

  1. Anda perlu menampal kod firebaseConfig daripada projek Firebase anda di ruangan di bawah (atau di dalam kod index.html).
  2. Di Firebase Console → Firestore Database → Rules, pastikan Test Mode diaktifkan: allow read, write: if true;
  3. Di Firebase Console → Authentication → Sign-in method, pastikan Anonymous telah diaktifkan (Enable).

Tips: Anda boleh tampal keseluruhan blok const firebaseConfig = { ... }; terus dari Firebase Console.

Ketetapan Sistem & Perlawanan

Tetapkan nama kejohanan, logo & watermark SHUTTLEPOWER, format set perlawanan, penentuan tempat ke-3/4, dan PIN akses.

Tajuk ini akan dipaparkan di bahagian paling atas sistem, poster pemenang, dan laporan rasmi.

Sistem membaca fail SHUTTLEPOWER.jpg atau Grafik Vektor Rasmi secara automatik. Anda juga boleh memuat naik fail imej logo terus di sini:

Jika memilih 2 Set (Best of 3), perlawanan mempunyai Set 1 & Set 2. Jika kedudukan set terikat 1-1, perlawanan akan diteruskan ke Set Ke-3 (Set Penentuan).

Boleh melihat kesemua menu sistem.

Hanya melihat Paparan Awam & Pengadil Skor.

Muat Turun Keputusan Penuh Kejohanan

Menunggu Akhir Tamat

Buka Semula (Restore) Kejohanan Dari Excel: Muat naik semula fail Excel Kejohanan (`.xlsx`) untuk memaparkan kembali kejohanan yang telah direset.
